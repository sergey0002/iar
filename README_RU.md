## 🌟 Почему именно iar?

| | Преимущество |
|:---:|:---|
| ⚡ | **Быстрая отдача** — Прозрачное кеширование + ETag + опциональный редирект 302/301 на статичный файл кеша. Повторные запросы — как статика. |
| 🛡️ | **Безопасен по умолчанию** — Защита от Path Traversal и DoS. Белые списки расширений и строгая проверка путей. |
| 📦 | **Ноль системных зависимостей** — Нужен только PHP + GD. Не требует `imagemagick` или глобального `composer` на сервере. |
| 🚀 | **Современные форматы** — Автоматически отдаёт WebP или AVIF, если браузер поддерживает (`Accept` header). |
| 📁 | **Полная поддержка подпапок** — Работает с любой глубиной вложенности директорий. |
| 🔧 | **Единая точка конфига** — Все настройки в одном файле `config.php`. Менять код не нужно. |

---

## 🧭 Концепция

IAR — **переносимая папка**, а не сервис:

- **Drop-in.** Кладёте папку в корень любого сайта, обращения к картинкам идут через неё. Ничего, кроме PHP + GD, не требуется; весь код и зависимости живут внутри папки.
- **Кеш полностью удаляемый.** Каталог `cache/` можно удалить целиком в любой момент — варианты пересоздаются при первом обращении по URL. Никаких «прогревов» и обязательных квот.
- **Лог — только для отладки.** По умолчанию **выключен** (`logging => false`), ротация не нужна. Включайте на время диагностики.
- **URL API стабилен.** Параметры `w`, `h`, `m`, `g`, `ct/cr/cb/cl`, `fm` не менялись.

## 🚀 Быстрый старт

### Установка

`iar` требует **Intervention Image v3**. Вы ДОЛЖНЫ установить зависимости через Composer **внутри** папки проекта.

**Способ А — через Git (рекомендуется):**

```bash
git clone https://github.com/sergey0002/iar.git
cd iar
composer install --no-dev --optimize-autoloader
```

**Способ Б — вручную:**

1. Скачайте и скопируйте папку `iar` в корень вашего сайта.
2. Откройте терминал и перейдите **внутрь** папки `iar`:

   ```bash
   cd /путь/к/сайту/iar
   ```

3. Установите зависимости.

   *Если глобальный `composer` установлен:*

   ```bash
   composer install --no-dev --optimize-autoloader
   ```

   *Если `composer` не установлен глобально — скачайте его локально:*

   ```bash
   php -r "copy('https://getcomposer.org/installer', 'cs.php');"
   php cs.php --filename=composer.phar --quiet
   php -r "unlink('cs.php');"
   php composer.phar install --no-dev --optimize-autoloader
   ```

> [!NOTE]
> Папка `cache/` создаётся **автоматически** при первом запросе. Убедитесь, что PHP-процесс имеет права на запись в директорию `iar/`.

> [!TIP]
> Папку `iar/` можно **переименовать** на любое другое имя — всё будет работать корректно. Правила `.htaccess` относительные и переносимые.

## 📖 Примеры использования

> **Принцип:** обращайтесь к изображению по его оригинальному пути через папку `iar/`. Система сама найдёт файл, обработает и закеширует результат.

### Базовый ресайз

`/products/hero.jpg` — реальный путь к изображению в корне сайта.

```html
<!-- Ресайз до 800px по ширине, высота пропорционально -->
<img src="/iar/products/hero.jpg?w=800">

<!-- Только по высоте -->
<img src="/iar/products/hero.jpg?h=600">
```

### Адаптивные изображения (`srcset`)

```html
<img
  src="/iar/products/hero.jpg?w=1200"
  srcset="
    /iar/products/hero.jpg?w=480 480w,
    /iar/products/hero.jpg?w=800 800w,
    /iar/products/hero.jpg?w=1200 1200w
  "
  sizes="(max-width: 600px) 480px, (max-width: 1000px) 800px, 1200px"
  alt="SEO-оптимизированное фото"
  loading="lazy">
```

### Изображения в подпапках

```html
<!-- /catalog/phones/2026/iphone15.jpg — оригинальный путь -->
<img src="/iar/catalog/phones/2026/iphone15.jpg?w=400&h=400&m=cover">

<!-- Глубокая вложенность -->
<img src="/iar/assets/img/ui/icons/logo.png?w=100">
```

### Квадратный аватар с умным кропом

```html
<!-- Кроп по центру (дефолт), 200×200 -->
<img src="/iar/users/avatar.jpg?w=200&h=200&m=cover">

<!-- Кроп с акцентом на верхней части (портрет) -->
<img src="/iar/users/profile.jpg?w=300&h=300&m=cover&g=top">
```

### Обложка статьи с обрезкой краёв

```html
<!-- Срезать 15% снизу (убрать водяной знак), потом ресайз -->
<img src="/iar/blog/cover.jpg?w=1200&h=400&cb=15p&m=cover&g=top">

<!-- Срезать 50px сверху и ресайз -->
<img src="/iar/photo.jpg?w=640&h=480&ct=50">
```

### Принудительная конвертация формата

```html
<!-- Всегда отдавать WebP, независимо от браузера -->
<img src="/iar/logo.png?w=200&fm=webp">

<!-- Конвертировать в AVIF -->
<img src="/iar/photo.jpg?w=800&fm=avif">
```

### Короткие пути: псевдонимы, пресеты и макросы

Один файл `aliases.json` рядом с `index.php` превращает короткий URL в реальный
путь и в параметры обработки. Файл уже в репозитории и работает сразу.

```html
<!-- Псевдоним каталога: z → /z/s/d/f/ -->
<img src="/iar/z/file.png">

<!-- Папка-пресет: 1000 = максимальная ширина 1000 -->
<img src="/iar/1000/file.png">

<!-- Макрос: x-2000 = только ширина, y-1000 = только высота -->
<img src="/iar/x-2000/file.png">
<img src="/iar/y-1000/file.png">

<!-- Псевдоним + пресет вместе -->
<img src="/iar/z/thumb/file.png">
```

```json
{
    "aliases":  {"z": "/z/s/d/f/", "img": "/assets/images/"},
    "presets":  {"1000": {"w": 1000}, "thumb": {"w": 300, "h": 300, "m": "cover"}},
    "macros":   {"enabled": true, "width": "x-", "height": "y-"}
}
```

Главное: реальный файл всегда важнее виртуального маршрута, явный `?w=` важнее
папки-пресета, пресет важнее маски, а виртуальной может быть **только последняя
папка** перед именем файла. Сломанный JSON не ломает картинки — маршруты просто
выключаются, причина уходит в лог.

Подробности, приоритеты и безопасность: [**docs/path-routing.md**](docs/path-routing.md).

## 🔗 URL API — Полный справочник параметров

### Основные параметры

| Параметр | Тип | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| *(путь в URL)* | string | — | Путь к оригиналу, передаётся как суффикс URL: `/iar/путь/к/файлу.jpg` |
| `w` | int | `0` | Ширина в px. `0` = не ограничивать |
| `h` | int | `0` | Высота в px. `0` = не ограничивать |

### Режим масштабирования (`m`)

| Значение | Поведение |
| :--- | :--- |
| `fit` *(по умолчанию)* | Пропорционально вписывает в `w×h`. Не обрезает. Не увеличивает маленькие изображения. |
| `cover` | Заполняет всю область `w×h` без искажений. Края обрезаются по точке `g`. |
| `resize` | Строго растягивает в `w×h`, игнорируя пропорции. Может искажать. |

### Гравитация (`g`) — только для `m=cover`

| Значение | Точка привязки |
| :--- | :--- |
| `center` *(по умолчанию)* | Центр |
| `top` | Верх по центру |
| `bottom` | Низ по центру |
| `left` | Левый центр |
| `right` | Правый центр |
| `top-left` | Верхний левый угол |
| `top-right` | Верхний правый угол |
| `bottom-left` | Нижний левый угол |
| `bottom-right` | Нижний правый угол |

### Обрезка краёв (`ct`, `cr`, `cb`, `cl`)

Обрезает указанное количество пикселей или процентов с края **перед** ресайзом.

| Параметр | Край | В пикселях | В процентах |
| :---: | :--- | :---: | :---: |
| `ct` | Верх (top) | `?ct=50` | `?ct=15p` |
| `cr` | Право (right) | `?cr=10` | `?cr=10p` |
| `cb` | Низ (bottom) | `?cb=30` | `?cb=20p` |
| `cl` | Лево (left) | `?cl=20` | `?cl=5p` |

> [!NOTE]
> Суффикс `p` означает проценты (`0`–`100`). Одновременно активен только **один** параметр: приоритет `ct → cr → cb → cl`; при нескольких в ответ добавляется `X-Iar-Warning`.
>
> Значение в пикселях больше стороны изображения ограничивается так, чтобы оставался минимум 1 пиксель. Процент вне `0`–`100`, отрицательные и нечисловые значения дают `400`. Чёрных/белых полос на результате больше нет.

### Формат вывода (`fm`)

| Значение | Описание |
| :--- | :--- |
| `webp` | Принудительно конвертировать в WebP |
| `avif` | Принудительно конвертировать в AVIF |
| `jpg` / `jpeg` | Сохранить как JPEG |
| `png` | Сохранить как PNG |
| `gif` | Сохранить как GIF |
| `svg` | Только если оригинал — SVG (для растра → `400`) |

> Регистр не важен: `fm=WEBP` работает так же, как `fm=webp`.
>
> Если `fm` не передан и включён `auto_format`, формат выбирается по `Accept`. **GIF и SVG автоматически не конвертируются** — сохраняется анимация и вектор. `Vary: Accept` отправляется только тогда, когда ответ действительно зависит от `Accept`.

## ⚙️ Конфигурация `config.php`

Единственная точка настройки. Менять код в других файлах не нужно.

```php
return [
    // === Качество и размеры ===
    'max_width'       => 2000,   // Максимальная ширина (защита от DoS)
    'max_height'      => 2000,   // Максимальная высота
    'jpeg_quality'    => 82,     // JPEG: 1–100 (82 = стандарт индустрии)
    'webp_quality'    => 85,     // WebP: 1–100
    'avif_quality'    => 75,     // AVIF: 1–100

    // === Защита от DoS: лимиты ВХОДНОГО изображения ===
    'max_input_megapixels' => 40,      // Мп; проверка до декодирования
    'max_input_bytes'      => 20000000, // байт (~20 МБ)

    // === Оптимизация PNG ===
    'png_indexed'           => true,  // Умный indexed PNG для маленьких (экономит 30–70%)
    'png_indexed_threshold' => 200,   // px: шире этого — остаётся true-color; 0 = всегда

    // === Оптимизация JPEG ===
    'jpeg_progressive' => true,       // Прогрессивный JPEG (плавная загрузка сверху вниз)

    // === Оптимизация WebP ===
    'webp_strip_metadata' => true,    // Удалять EXIF/XMP из WebP (экономит 1–5 KB)

    // === Режимы по умолчанию ===
    'default_mode'    => 'fit',       // fit | cover | resize
    'default_gravity' => 'center',    // center | top | bottom | left | right | ...

    // === Оптимизация и кеширование ===
    'lossless'           => false,    // true = максимальное качество (quality 100)
    'auto_format'        => true,     // Авто-выбор WebP/AVIF по Accept-заголовку
    'cache_invalidation' => 'mtime',  // 'mtime' (по дате оригинала) | 'off' (вечный кеш)
    'cache_auto_clean'   => true,     // Удалять старые версии кеша при обновлении
    'redirect_to_cache'  => true,     // true = редирект 302/301 на статичный файл кеша
    'static_mode'        => false,    // true = без проверки mtime, 301 редирект (макс. скорость)
    'disable_cache'      => false,    // true = отключить кеш (перегенерация всегда, для разработки)
    'cache_key_config_hash' => true,  // смена качества инвалидирует кеш

    // === Безопасность и пути ===
    'images_base_dir'    => __DIR__ . '/../',   // проверяется при загрузке; плохой путь — явная ошибка
    'allowed_extensions' => ['jpg', 'jpeg', 'gif', 'png', 'webp', 'avif', 'svg'],
    'cache_dir'          => __DIR__ . '/cache',
    'aliases_file'       => __DIR__ . '/aliases.json', // маршруты: псевдонимы, пресеты, макросы

    // === Логирование ===
    'logging' => false,   // отладочный лог; по умолчанию выключен
    'log_dir' => __DIR__ . '/log',
];
```

### Описание всех параметров конфигурации

| Ключ | Значение | Описание |
| :--- | :---: | :--- |
| `max_width` / `max_height` | int, px | Верхний предел размеров. Значения `w`/`h` больше лимита обрезаются. **Защита от DoS.** |
| `jpeg_quality` | 1–100 | Качество JPEG. `82` — визуально без потерь, оптимальный размер файла. |
| `webp_quality` | 1–100 | Качество сжатия WebP (lossy). `85` — рекомендуется. |
| `avif_quality` | 1–100 | Качество AVIF. `75` — отличный баланс качества и размера. |
| `png_indexed` | bool | Умный режим индексированных цветов (256-цветная палитра) для PNG. Экономит 30–70% для иконок и flat-арта. |
| `png_indexed_threshold` | px | Ширина, выше которой indexed-режим отключается (изображение остаётся true-color). `0` = всегда indexed. |
| `jpeg_progressive` | bool | Прогрессивный JPEG — картинка загружается плавно сверху вниз в браузере. |
| `webp_strip_metadata` | bool | Удалять EXIF/XMP метаданные из WebP. Экономит 1–5 KB на файл. |
| `default_mode` | `fit` / `cover` / `resize` | Режим масштабирования по умолчанию, если `m` не передан в URL. |
| `default_gravity` | `center` / ... | Точка кропа по умолчанию для режима `cover`, если `g` не передан. |
| `lossless` | bool | `true` = все форматы в максимальном качестве (JPEG/WebP/AVIF quality=100, PNG без сжатия). |
| `auto_format` | bool | Автоматически отдавать WebP / AVIF, если браузер сообщает о поддержке через `Accept`. |
| `cache_invalidation` | `mtime` / `off` | `mtime` — пересоздавать кеш при изменении оригинала. `off` — кеш вечный. |
| `cache_auto_clean` | bool | Удалять старые версии кеш-файла при обновлении оригинала. |
| `redirect_to_cache` | bool | `true` = PHP делает 302/301 редирект на статичный файл в `cache/` (Apache отдаёт напрямую). `false` = поток через PHP. |
| `static_mode` | bool | `true` = пропустить проверку `filemtime` полностью (минимум I/O), 301 редирект. Для неизменяемых ресурсов. |
| `disable_cache` | bool | `true` = отключить кеш (всегда перегенерировать). Посылает заголовки `no-cache`. **Только для разработки.** |
| `images_base_dir` | path | Корневая директория оригиналов. Запросы за её пределы — 403. |
| `allowed_extensions` | array | Белый список расширений. Всё остальное возвращает 403. |
| `cache_dir` | path | Папка для хранения кешированных миниатюр. Создаётся автоматически. |
| `max_input_megapixels` | int, Мп | Предел размера **оригинала**; проверяется до декодирования. Превышение → `413`. |
| `max_input_bytes` | int, байт | Предел веса оригинала. Превышение → `413`. |
| `cache_key_config_hash` | bool | Включать отпечаток настроек качества в кеш-ключ: смена качества сразу даёт новый вариант. |
| `logging` | bool | Отладочный лог. **По умолчанию `false`.** |
| `log_dir` | path | Директория для лог-файлов (один файл в день). |
| `log_level` | `error` / `info` / `debug` | `error` (по умолчанию) — только сбои с причиной; `info` — плюс hit/miss; `debug` — плюс параметры запроса. На `error` метрики не собираются, горячий путь не делает лишних обращений к диску. |
| `aliases_file` | path | Путь к JSON маршрутов (псевдонимы каталогов, пресеты и макросы последней папки). По умолчанию — `aliases.json` рядом с `index.php`. См. [docs/path-routing.md](docs/path-routing.md). |

### Сравнение режимов кеша

| Режим | Конфиг | Поведение | Когда использовать |
| :--- | :--- | :--- | :--- |
| **Обычный** | по умолчанию | Проверка mtime + 302 редирект | Изменяемые ресурсы |
| **Статичный** | `static_mode: true` | Без проверки mtime + 301 редирект | Неизменяемые ресурсы |
| **Разработка** | `disable_cache: true` | Всегда перегенерировать | Разработка |

## ✨ Возможности системы

| Возможность | Описание |
| :--- | :--- |
| **Ресайз** | Пропорциональный ресайз по ширине (`w`) или высоте (`h`). Не увеличивает маленькие изображения. |
| **Умный кроп** | Режим `cover` с выбором точки фокуса (`g`). |
| **Маршруты в пути** | Псевдонимы каталогов, папки-пресеты и макросы `x-`/`y-` из `aliases.json`. |
| **Обрезка краёв** | Срезать px или % с любого края перед обработкой (`ct`, `cr`, `cb`, `cl`). |
| **Авто WebP/AVIF** | Прозрачная конвертация в современные форматы без изменения URL. |
| **Прозрачное кеширование** | Первый запрос = обработка. Все последующие = мгновенная отдача из кеша. |
| **Редирект на кеш** | PHP делает редирект на статичный файл кеша — Apache отдаёт напрямую без PHP. |
| **Статичный режим** | Нулевые I/O-накладные расходы для неизменяемых ресурсов. |
| **Режим разработки** | `disable_cache` — всегда свежие изображения без ручной очистки кеша. |
| **Инвалидация кеша** | Автоматически при изменении оригинала (по `mtime`). |
| **ETag / 304** | Полная поддержка браузерного кеширования. |
| **Прогрессивный JPEG** | Плавная загрузка сверху вниз. |
| **Умный PNG indexed** | Автоматический режим палитры для маленьких PNG (экономия 30–70%). |
| **Стриппинг WebP** | Удаление EXIF/XMP из WebP на лету. |
| **Поддержка SVG** | SVG передаётся как есть (или растеризуется через Imagick). |
| **Path Traversal защита** | Строгая проверка пути — невозможно выйти за пределы `images_base_dir`. |
| **DoS защита** | Лимиты результата (`max_width`/`max_height`) **и входа** (`max_input_megapixels`/`max_input_bytes`, проверка до декодирования → `413`). |
| **Lossless режим** | Глобальное максимальное качество одним параметром конфига. |
| **Отладочный лог** | JSON-строки: статус кеша, экономия размера, причина сбоя. Выключен по умолчанию, чувствительные ключи редактируются. |
| **Атомарный кеш** | Запись во временный файл + `rename`, `flock` против stampede. |
| **Безопасный SVG** | `Content-Security-Policy` и `nosniff` и на PHP-пути, не только в Apache. |
| **HEAD и 405** | Корректный `HEAD` без тела, `405` + `Allow` для остальных методов. |
| **100% покрытие тестами** | Юнит + интеграционные HTTP-сценарии, порог покрытия в CI. |

## 🏗 Архитектура и поток запроса

```
index.php            тонкая точка входа (зависимости + запуск)
└── App\Bootstrap    display_errors=0, обработчик фатальных ошибок, сборка
    ├── App\Config           типизированный конфиг с валидацией (fail-fast)
    ├── App\Http\Request    разбор и валидация параметров (400/405)
    ├── App\Application      оркестрация: путь → ключ → кеш → ответ
    │   ├── App\Domain\FormatNegotiator  выбор формата по Accept
    │   ├── App\Domain\ResizeService     Intervention Image (GD)
    │   │   └── App\Domain\SvgRasterizer → ImagickRasterizer
    │   ├── App\Infrastructure\CacheKey   ключ варианта
    │   ├── App\Infrastructure\CacheStore атомарная запись + flock
    │   └── App\Infrastructure\DebugLogger|NullLogger
    └── App\Http\Response → SapiInterface (NativeSapi в бою, TestSapi в тестах)
```

Поток: `resolveSource` (realpath + белый список) → параметры → целевой формат →
`mtime` → кеш-ключ → есть файл? отдача : блокировка → генерация → атомарная
публикация → отдача (или редирект на статику).

Кеш-ключ включает **полный относительный путь** оригинала, размеры, режим,
гравитацию, кроп, `mtime` и отпечаток настроек качества — коллизии между
`/photo.jpg` и `/www/photo.jpg` больше невозможны.

## 🧪 Тестирование

Тесты не требуют ни PHPUnit, ни Xdebug — это часть концепции портабельности.

```bash
# Юнит-тесты без composer и PHPUnit
php tests/run.php

# Интеграционные HTTP-сценарии (встроенный сервер PHP, реальные заголовки)
php tools/integration.php run

# Покрытие строк без Xdebug/PCOV + порог 100%
php tools/coverage-portable.php build
php tests/coverage-run.php
php tools/integration.php run
php tools/coverage-portable.php report 100

# Совместимость с PHP 7.0 … 8.4 (без composer, без PHPUnit)
php tests/legacy-compat.php

# Замер обращений к диску на cache hit
php tools/io-probe.php build
php tools/integration.php setup 0 /tmp/iar-probe
php tools/integration.php payload 0 0 /tmp/iar-probe "" probe > /tmp/p.json
php tests/Integration/step.php /tmp/p.json   # MISS
php tools/io-probe.php reset
php tests/Integration/step.php /tmp/p.json   # HIT
php tools/io-probe.php report
```

С Composer доступны привычные команды:

```bash
composer test              # PHPUnit
composer test-all          # портативный раннер + интеграция
composer coverage          # clover-отчёт
composer coverage-gate     # порог 100% по clover
composer coverage-portable # независимая проверка покрытия
composer stan              # PHPStan
composer cs                # PHP-CS-Fixer (dry-run)
composer mutation          # Infection, MSI ≥ 90
```

Что проверяется: валидация параметров, границы кропа, коллизии кеш-ключа,
белые списки форматов, анимация GIF, заголовки/304/редиректы, инвалидация,
**полный сброс кеша → пересоздание**, лимиты DoS, SVG-CSP, отказ записи в кеш,
гонка воркеров, фатальные ошибки, маршруты из `aliases.json` (приоритеты,
паритет двух движков, сломанный JSON).

Текущие результаты: **663 юнит-теста** (662 пройден, 1 пропущен — GD без AVIF),
**62 из 62** HTTP-сценариев, покрытие строк **1449/1449 = 100 %**, PHP **7.0 → 8.4**

## 🚢 Развёртывание

### Apache

`.htaccess` уже настроен: `-Indexes`, запрет служебных файлов и каталогов
(`config.php`, `aliases.json`, `log/`, `vendor/`, `src/`, `tests/`, dotfiles, `.git/`),
пропуск существующих файлов кеша мимо PHP, `[B]` в rewrite (имена с `&`),
`nosniff` и CSP для SVG. Требуется `mod_rewrite` и `AllowOverride All`.

### nginx

```nginx
location /iar/ {
    # существующие файлы кеша отдаём напрямую
    try_files $uri @iar;
}

location @iar {
    rewrite ^/iar/(.*)$ /iar/index.php?name=$1 last;
}

location = /iar/index.php {
    fastcgi_pass unix:/run/php/php-fpm.sock;
    include fastcgi_params;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
}

location ~ ^/iar/(config\.php|aliases\.json|composer\.|src/|tests/|tools/|log/|vendor/|\.) {
    deny all;
}
```

### Очистка кеша — точечная, без удаления всей папки

```bash
php tools/cache.php stats                      # сколько файлов, вес, сколько оригиналов
php tools/cache.php clean --source=photo.jpg   # все варианты одного оригинала
php tools/cache.php clean --orphans            # варианты удалённых оригиналов
php tools/cache.php clean --older-than=30d     # давно не создававшиеся варианты
php tools/cache.php clean --max-size=500M      # самые старые, пока вес больше лимита
php tools/cache.php wipe                       # всё содержимое кеша
```

Любая команда принимает `--dry-run`. Инструмент работает на PHP 7.0+ без
зависимостей и не читает содержимое файлов: имя варианта содержит хеш
относительного пути оригинала, поэтому поиск точечный.

Полный сброс тоже допустим:

```bash
rm -rf /путь/к/сайту/iar/cache/*
```

Ничего прогревать не нужно: следующий запрос по URL пересоздаст вариант.

### Диагностика

| Симптом | Причина | Решение |
| :--- | :--- | :--- |
| `X-Iar-Engine: legacy` | PHP < 8.1 или нет `vendor/` | это нормально: работает движок без зависимостей; для полного — PHP 8.1+ и `composer install --no-dev -o` |
| `500 IAR installation is incomplete` | в папке нет ни `vendor/`, ни `legacy.php` | распакуйте папку IAR целиком |
| `500 Configuration error.` | неверный `images_base_dir` или тип значения | проверьте `config.php`, ошибка намеренно явная |
| `302` на оригинал вместо миниатюры (`X-Iar-Fallback: original`) | GD не смог обработать файл или конвертация потеряла бы анимацию | включите `logging => true`, посмотрите `reason` в `log/` |
| `X-Iar-Cache: miss` на каждом запросе | `disable_cache => true` или оригинал постоянно меняется | проверьте конфиг и mtime оригинала |
| `413` | оригинал больше `max_input_megapixels` / `max_input_bytes` | уменьшите оригинал или поднимите лимит |
| Фото повёрнуто неверно | нет `ext-exif` | установите `php-exif` |
| SVG не растеризуется | нет `ext-imagick` | установите `php-imagick` или отдавайте SVG как есть |
| AVIF не отдаётся | GD собран без AVIF | обновите GD; WebP выбирается автоматически |

## ⚠️ Изменения относительно 1.x

| Что | Было | Стало |
| :--- | :--- | :--- |
| `logging` | `true` | **`false`** (концепция: лог только для отладки) |
| `png_compression` | документирована | **удалена** — не работала |
| `fm=svg` для растра | JPEG с расширением `.svg` | `400` |
| GIF + `Accept: image/webp` | терялась анимация | GIF сохраняется |
| `ct=-50`, `ct=150p` | полосы/чёрное поле | `400` либо корректный clamp |
| `Cache-Control` | `immutable` на год всегда | `no-cache`; `immutable` только в `static_mode` |
| `304` | без заголовков | с `ETag`, `Cache-Control`, `Vary` |
| POST/PUT | обрабатывался как GET | `405` + `Allow` |
| Массив в `w`/`h` | `500` | `400` |
| Оригинал 140 Мп | фатальный OOM | `413` до декодирования |
| Запрос без параметров | перекодирование | копия байтов оригинала |

URL API не изменился: существующие ссылки продолжают работать.

## 📋 Системные требования

| Компонент | Минимум | Рекомендуется |
| :--- | :---: | :---: |
| PHP | **≥ 7.0** (движок `legacy.php`) | 8.1+ (полный движок `src/`) |
| PHP GD extension | ✅ Обязательно | + WebP + AVIF support |
| Apache `mod_rewrite` | — | ✅ Для красивых URL |
| `php-exif` | — | ✅ Корректная ориентация JPEG |
| `php-imagick` | — | ✅ Для SVG → растр |
| Composer | **не нужен** | ✅ Для полного движка (Intervention Image) |

### Два движка — один URL API и один кеш

| | `legacy.php` | `src/` (Intervention) |
| :--- | :--- | :--- |
| Когда включается | PHP 7.0–8.0 **или** нет `vendor/` | PHP ≥ 8.1 и установлен Composer |
| Зависимости | нет (только GD) | `intervention/image` |
| Кеш | **тот же каталог и те же имена файлов** | **тот же каталог и те же имена файлов** |
| URL API, заголовки, ETag, 304 | идентичны | идентичны |
| Анимированный GIF | отдаётся оригиналом | ресайз с сохранением кадров; смена формата → оригинал |
| Анимированный WebP | отдаётся оригиналом | отдаётся оригиналом |
| SVG → растр | только с `ext-imagick` | только с `ext-imagick` |
| AVIF | если GD умеет | если GD умеет |

Переключение автоматическое и незаметно для браузера: имена кеш-файлов
совпадают побайтово (проверяется тестами `LegacyTest`), поэтому переезд
с PHP 7 на PHP 8 не требует ни сброса кеша, ни изменения ссылок.
Движок, ответивший на запрос, виден в заголовке `X-Iar-Engine`.
